# 계속기업 감사보조 시제품 v0.1

외부감사 업무팀이 계속기업 위험의 발견 근거와 후속 절차, 수행·검토 기록을 연결하는 도구의 첫 시제품입니다.

**현재는 가상자료로 동작합니다. DART·생성형 AI·공식 감사기준 원문·보고서 업로드는 아직 연결하지 않았습니다.**

- [팀 공유: 진행 현황·담당 역할·일주일 계획](TEAM_BRIEF.md)
- [바로 전달할 팀 공지 초안](TEAM_MESSAGE.md)
- [팀원 작성 양식](TEAM_INPUTS.md)

GitHub는 코드와 문서를 공유하는 곳입니다. 저장소에 올려도 앱이 자동 배포되거나 팀원들의 SQLite 기록이 서로 동기화되지는 않습니다. 각자 내려받아 실행하면 각자 컴퓨터에 별도 데이터가 저장됩니다.

## 실행

Windows에서 `start.cmd`를 실행합니다. 브라우저가 자동으로 열립니다.
GitHub의 Code → Download ZIP으로 내려받아 압축을 푼 뒤 실행하세요. Python 3.10 이상이 필요합니다.
주소: http://127.0.0.1:8765
Python 3.10 이상이면 추가 패키지 없이 `python app.py`로 실행할 수 있습니다.
종료는 실행 창에서 Ctrl+C를 누릅니다. 한 번에 서버 하나만 실행하세요.

## 현재 구현

- 가상기업 3개, 2025년 별도 업무 및 3개년 비교 자료
- 신호 5개와 계산·자료 부족 처리, 발견 근거·고정 절차 예시
- 신호별 수행자, 요청 자료, 절차, 선택 이유, 증거 참조, 결과, 결론, 미해결 사항
- 검토 요청과 다른 이름의 검토자 기록, 검토 완료 전 필수 입력 확인
- SQLite 저장, 변경 전 버전 비교, 이력 스냅샷, 한글 TXT 조서 초안

## 시연 방법

1. 가상 A제조에서 영업현금흐름 카드를 열고 수치·점검 규칙을 확인합니다.
2. 절차 작성에서 수행자와 선택 이유, 증거 참조, 실제 수행 결과, 결론을 입력합니다. 가상 수행 내용임을 명시하세요.
3. 상태를 검토 요청으로 저장합니다.
4. 다른 팀원이 검토자와 검토 의견을 입력하고 검토 완료로 저장합니다. 미해결 사항이 있으면 완료할 수 없습니다.
5. 검토·조서 화면에서 TXT를 다운로드합니다.
6. B기업에서 신호 미검출, C기업에서 자료 부족을 확인합니다.

## 범위와 제한

모든 기업·수치·문구 존재 여부는 가상입니다. 실제 DART, 공시 문장 분석, 생성형 AI, 기준 원문은 미연결입니다. 계산 임계값과 절차는 검토 전 개발 예시입니다. 기준 문구를 임의로 인용하지 않습니다.

증거는 참조 텍스트만 저장하며 첨부파일을 보관하거나 진위를 확인하지 않습니다. 이름 입력은 로그인·본인확인이 아닙니다. 검토 완료는 시연 업무의 상태이며 감사품질 승인이나 기준 연결 완료를 의미하지 않습니다. 기밀자료를 입력하지 마세요.

가상 업무의 기간·연결/별도는 고정되어 있습니다. 자료 부족 시나리오는 입력자료 수정 기능이 없으므로 검토 완료를 보류합니다. 문구 탐지는 사전 입력값을 사용합니다. AI 생성 결과처럼 표시하지 않습니다.

데이터는 `data/audit.sqlite3`에 저장됩니다. 서버를 종료한 뒤 data 폴더를 복사하면 백업할 수 있습니다. 앱 폴더와 DB는 로컬 파일이며 공개 배포·동시 공동 작업용 서버가 아닙니다.

## 검증

`python -m unittest -v test_app`

자동 검증은 계산 경계, 누락, 저장, 상태 전환, 버전 충돌, 출력 내용 등을 다룹니다. 감사기준과 실무 적합성은 별도 팀 검토가 필요합니다.

초기 개발 검증: 자동 테스트 12개 통과. 브라우저에서 가상 입력 → 검토 요청 → 교차검토 완료 → TXT 다운로드 → 재접속 후 저장 유지 확인.

## 저장소 구성

`app.py`: 서버·규칙 계산·SQLite 저장 / `index.html`: 한국어 화면 / `dart_fetch.py`: OpenDART 실제 기업 공시 스냅샷 수집 / `test_app.py`: 자동 검증 / `TEAM_*.md`: 팀 공유 자료

`site/`: 설치 없는 온라인 시연판(localStorage 저장). `python site/prepare.py`로 루트의 `app.py`·`index.html`에서 `site/dist/`를 다시 생성합니다. 검증은 `node --test site/demo.test.cjs`(Node.js 필요).

## OpenDART 실제 기업 데이터 연동 (선택)

1. `.env.example`을 `.env`로 복사하고 `DART_API_KEY=발급받은40자리키`를 입력합니다 (`.env`는 Git에 포함되지 않습니다).
2. 기업 검색: `python dart_fetch.py --find 회사명`
3. 3개년 공시 스냅샷 생성: `python dart_fetch.py --stock 6자리종목코드 --year 2025` (연결 기준은 `--fs CFS` 추가)
4. 생성된 `cases/real_*.json`은 공개 공시 수치와 접수번호만 담고 있어 서버(`app.py`)와 온라인 시연판(`python site/prepare.py`)에서 인증키 없이 바로 불러옵니다.

실행 시 생성되는 `data/`와 개인정보·인증키를 담을 수 있는 `.env`, 내보낸 조서는 Git에 포함하지 않습니다.
